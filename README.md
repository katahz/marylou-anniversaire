# Marylou · Éclipse à Tanger

Page cadeau statique (GitHub Pages, `main` → `/`).

- `index.html` : page mobile. « Commencer l'aventure » lit `eclipse-tanger.mp4` (1080×1920, son au toucher).
- `Tanger_Eclipse_v3_AR.glb` : modèle animé pour la réalité augmentée.
- Pour activer la réalité augmentée, ajouter `carte.mind` (compilé avec MindAR depuis l'image du motif imprimé) à la racine.
  Le bouton « Activer la caméra » apparaît alors automatiquement, à la même adresse ; la version sans caméra reste accessible.
